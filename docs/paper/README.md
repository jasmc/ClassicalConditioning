# Paper workspace

[Figures 1–4](figures/README.md) lead this workspace. Each figure owns its composition, legend and specific review concerns; panel folders exist only where there is substantial scoped work.

- [Shared methods](methods/README.md): definitions and contracts used by more than one figure.
- [Scientific decisions](decisions.md): current scoped choices and approval evidence.
- [Paper review](review.md): questions spanning figures or affecting the paper's claims.
- [Figure workflow](figures/shared/iteration-workflow.md): frozen display, active draft and guarded publication.

Future implementation belongs in Plans. Exact accepted bytes and supporting evidence are linked from records. A presentation draft is not a scientific freeze.
