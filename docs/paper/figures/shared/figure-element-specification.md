# Figure element identities and freeze contract

This is the maintained explanation of the semantic extension in contract 1.1.2.
The [machine-readable role contract](../../../../configs/paper-figures/figure-elements.json)
keeps role identifiers, allowed representations and compatibility defaults.
New paper presentation work resolves the [Nature target](nature-style.md) and
its profile overrides; historical typography is not another styling choice.

The byte-sensitive [original 1.1.1 specification](../../../analysis/figures/FIGURE_ELEMENT_SPECIFICATION.md)
retains its original bytes and path. Its inspected source inventories and role
explanations remain historical reference. The later 1.1.2 source is preserved
[exactly](../../../../records/repository-history/2026-10-17-organization-reconciliation/original-documents/docs/analysis/figures/FIGURE_ELEMENT_SPECIFICATION.md)
for hash-addressed recovery. Maintaining this explanation does not revise any
accepted scientific source, figure selection or frozen artifact.

## Semantic representation extension

The 13 October E freeze maps `trace.scaled_vigor_series` to framewise vigor
with an explicit baseline/scaling context, preserving the measured trace
defaults. `heatmap.vigor` also accepts direct SVG rectangles and groups of
explicitly mapped cells. These additions name the existing renderer
representations; the extension did not change numerical style defaults.

Scientific roles need explicit source/data mappings. Record quantity, units,
transformations, timing, eligibility, normalization, coordinate system and
linked-panel relationships from authenticated inputs. Structural XML IDs,
colours or visual similarity do not establish scientific identity. Use the
[scoped selections](../../../../records/frozen-analyses/selections.md) and their
exact accepted manifests for scientific definitions; retain original source
panel IDs when a presentation mapping changes displayed order.

## Explicit freeze procedure

Only an explicit freeze request activates candidate preparation and the freeze
gate. The [iteration workflow](iteration-workflow.md#what-happens-when-the-author-freezes)
owns source protection, scientific/visual review, approved scoped exceptions,
final-scale evidence, `--check-only` validation and guarded publication.
The [Nature guidance](nature-style.md#coding-entry-point-and-exact-values)
owns current profile resolution. Prepare a separate candidate and bind the
actual contract/profile inputs; never infer compliance from profile selection.

The gate validates already-prepared mappings and evidence. It does not infer
scientific roles, restyle artwork, approve methods or perform visual review.
Normal exports and repository maintenance do not create freezes. Preserve
historical contracts and accepted bytes; prior-version archival or deletion
requires its applicable author disposition and verified storage procedure.
