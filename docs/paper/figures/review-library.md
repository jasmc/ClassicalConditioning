## Refresh and verification

The [catalogue](review-library.json) records the reviewed targets and external hashes. Supported publication uses `python scripts/review_library.py build`; `check --external` verifies all listed SSD identities first. The builder creates new source-reading snapshots before replacing its navigation page, preserves existing reviews and stops on manual index/snapshot edits. Its generated Markdown index and reading copies are dated convenience snapshots. Canonical editable guidance remains in the repository.

Use [the organization review](../../../records/repository-history/2026-10-23-repository-output-review/README.md) for coverage, preserved navigation originals and unresolved cross-machine provenance.
