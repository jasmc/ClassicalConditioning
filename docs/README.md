# Project documentation

Start with the [paper figures](paper/figures/README.md). This is the everyday workspace for scientific purpose, selected panels, legends and review.

| Area | Use it for |
|---|---|
| [Paper](paper/README.md) | Figures, shared scientific methods, decisions and paper-wide questions |
| [Running the analysis](running-analysis/README.md) | Commands, parameters, interfaces, outputs and troubleshooting |
| [Project maintenance](project-maintenance/README.md) | Where files belong, governance, storage and transfer procedures |
| [Preserved records](../records/README.md) | Exact freezes, audits, historical versions and archive recovery |
| [Future work](../Plans/README.md) | Numbered implementation plans and the single progress index |

Running-analysis documents explain **how to run the code**. Project-maintenance documents explain **how to organize and preserve this project**. The code itself stays in `src/` and `scripts/`. Evidence stays in records; permanent media and numerical payloads stay on JOAQUIM.
