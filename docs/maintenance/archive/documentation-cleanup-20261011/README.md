## Author control assessment

The earlier organization did not create a sufficiently small everyday reading surface. Assessment of the current 150-file tree: 97 Markdown files, 52 JSON files and 1 CSV file; 53 files are archive/cleanup bookkeeping. The recommendations below are **proposed dispositions**, not executed renames/deletions. No new scientific decision or approval is made here.

Start with the five links in [the author control page](../../../README.md). The two competing panel-provenance/specification documents need coordinated rewriting: current selection notices do not make their older body text current. A suitable next structure is a small set of author records, figure-specific current guides, technical reference, historical evidence, and machinery in a records area. Moving machinery requires active resolver/tool/consumer changes; its exact recovery metadata must remain accessible.

Do not bulk-delete scientific history. There are no exact duplicates. The realistic deletion candidates are source documents whose unique content can first be integrated: overlapping provenance/specification, duplicate issue progress, and repetitive navigation. Preserve the removed source bytes or verified Git recovery identity before removal.
