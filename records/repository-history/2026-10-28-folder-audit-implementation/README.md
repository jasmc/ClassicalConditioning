identities and performed/unperformed verification. Characterization checks use
synthetic inputs or in-memory SVGs, not recomputed paper analyses. Unit tests,
source reconstruction, native runtime and browser evidence are distinct.

related tests. Those changes were preserved and not treated as this task's
publication or verification. Shared catalogue/recovery entries were reconciled
without discarding the other task's additions. The preservation report separates
our edits from observed concurrent changes rather than claiming every current
state stayed unchanged throughout the session.
