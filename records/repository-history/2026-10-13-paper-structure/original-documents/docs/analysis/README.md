# Analysis supporting documents

For accepted figure methods, start with [Current figures](../current-figures.md). Frozen versions define current; legacy and proposed methods are kept separate.

- [Technical references](reference/README.md): supported commands, pipeline internals, parameters and assembly tools.
- [Supporting decision evidence](decisions/README.md): reasoning behind the [central scientific decisions](../scientific-decisions.md).

- [Legacy references](legacy/README.md): inherited executable routes and method comparisons.
- [Exact frozen selection index](figures/freezes/README.md): current and accepted historical scopes.

Technical documentation describes implementation; it does not confer scientific approval. Unfinished work and status remain in [Plans](../../Plans/README.md).
