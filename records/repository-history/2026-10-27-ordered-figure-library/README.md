# Ordered figure library

The author approved implementation on 27 October 2026: register the storage
lifecycle rules, browse Figures 1–4 in order, and show one version at a time
through ordered panel/family/version buttons. The maintained review-library
builder now owns discovery, immutable working-artwork previews, publication
checks, version coverage and historical navigation recovery.

[Publication and verification](publication.json) binds the full SSD evidence.
All 114 focused tests pass. The audit verified 27,607 local targets, 365 protected
files, seven current states, 14 archive transactions and 67 reading entries.
Sixteen authority/selection files are byte-identical to the starting snapshot.
Four earlier navigation hashes and three selected-G bindings resolve exactly;
selected G has no dependency on the retired Mac root.

The catalogue accounts for 27,437 physical files and 6,028 artwork views, including
embedded artwork, explicit panel extractions and supporting/reference illustrations.
These counts do not assert 6,028 distinct scientific figure versions.

**Historical context coverage remains open:** 1,940 views lack an explicit saved
legend association. They remain accessible and are listed in each figure's
Coverage section and the complete version inventory. No substitute legend,
scientific meaning, selection, approval or freeze was invented. Manual-review
holds remain unchanged. Do not describe full historical coverage as complete.

Browser automation blocked file-URL navigation. Actual SSD files, links and SVG
resources were checked directly. Synthetic browser testing verified switching,
matching legends, arrow keys, Back navigation and joint-panel links; it is not
a claim of visual inspection of every SSD artifact.

Interrupted preparations preserved and restored prior entry points. Only two
unpublished task-created snapshots and unreferenced temporary generated files
were pruned after manifest/hash checks; current and hash-bound historical
navigation were retained. Raw/Digested Data and local artwork snapshots were
outside modification/deletion scope.
