## Disposition

- Retired from current guidance: universal DejaVu/old-size recommendations,
  historical D/E example-label and key typography, and the pre-Nature
  relationship-correction recipe as a route for new artwork. Compatible
  physical geometry, sharing, naming, ownership and scientific protections stay.
- Current instructions: AGENTS.md and the paper-figures skill require the
  Nature profile for new paper work. The maintained workflow and rendering
  guide resolve role values rather than teaching the old numerical defaults.
- Retained in place: `theme.py` unprofiled API, `DEFAULT_THEME` and `FigureTheme`
  defaults. Supported analysis/QC renderers and historical reproduction scripts
  still call them. Deleting or globally changing these would change supported
  output and frozen-reproduction behavior. Their source bytes were preserved.
- Retained in place: the original element specification, base role/style
  contract, frozen records, state-bound evidence and historical correction tools.
  The Nature resolver still inherits roles/colors from the base contract;
  immutable records and selected artwork are not disposable old styles.
- No renderer was automatically restyled. Remaining consumer integration stays
  with Plan 07; the retirement does not imply that those consumers use Nature.

The archived files are reference snapshots, not active guidance or selected
figure artifacts. Current authority remains the maintained Nature guide and
scoped figure state. Recovery can use the explicit archive path plus the exact
hash in the inventory; no live-path relocation is needed because sources remain.
