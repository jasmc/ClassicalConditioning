# Records

Exact frozen scientific definitions, manifests, settings and code live in [frozen-analyses](frozen-analyses/README.md), organized by figure, panel scope and dated version. Figures, numerical payloads and visual review containers live on JOAQUIM and are identified by the relocation indexes.

Use the [figure/panel catalogue](frozen-analyses/README.md) to find a record. Future records follow the same structure; decisions and active work plans remain under `docs/` and `Plans/`.
