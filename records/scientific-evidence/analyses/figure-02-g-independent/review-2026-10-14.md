## Findings, in priority order

1. **P1 — Acquisition uncertainty is not validated.** The population pilot's
   simultaneous curve bands missed the true curve in both abrupt and transient
   scenarios in all two repetitions for each target: eight failed full-curve
   coverage checks. Only two independent simulated experiments per
   scenario/target were run, with 39 bootstrap refits each. This cannot estimate
   nominal coverage or false-onset rates. Increasing resampling alone cannot
   remove approximation bias from a restrictive smooth mean curve. The abrupt
   examples' timing bounds did contain the simulated onset at trial 30;
   full-curve failure does not establish that those particular onset bounds
   failed. Nevertheless, general onset validity has not been demonstrated.
   Individual intervals also omit covariance-parameter uncertainty and show
   poor coverage in several pilot scenarios. The report correctly flags these
   limitations. Relevant code: `panel_g_review_extensions.py:154–216` and
   `panel_g_individual.py:104–119` under
   `src/classical_conditioning/analysis/inference/`.

2. **P1 — Individual validation does not use the final estimator.**
   `panel_g_missingness.py:14–23` uses all scheduled model trials for latent
   timing, with observed supported runs reported separately. In contrast,
   `panel_g_review_extensions.py:102` and `:210` still restrict leave-one-control-out
   and simulation timing to observed trials. The final correction changed
   33/456 point estimates, including eight at the candidate 10% threshold,
   60 earliest bounds and ten latest bounds. The checks therefore validate a
   different rule. Use one timing function in fitting, simulation and control
   validation; save the control-validation trajectories. Apply and calibrate
   the same information rule in each route. Keep sampled-run evidence as its
   own output.

3. **P1 — The important availability mechanism has not been tested.**
   Conditional vigor is undefined for no-bout windows. Available paired vigor
   outcomes are 2260/2520 in controls and 2551/2610 in Delay: unavailable
   fractions 10.3% and 2.3%. The simulation at
   `panel_g_review_extensions.py:144` randomly deletes outcomes independently
   of vigor within condition, including the unequal-coverage scenario. It does
   not simulate behavior-dependent bout availability or detector failure.
   Whole-fish resampling preserves the observed pattern; it does not establish
   that analyzing available conditional outcomes identifies a whole-cohort
   activity effect. Distinguish structural undefined vigor from missing
   measurements of a defined quantity. Define the conditional-vigor claim,
   validate the movement-occurrence outcome and stress availability that
   depends on response, baseline, phase and detector coverage. Do not impute
   zero conditional vigor for no-bout trials. The need to define the estimand
   and missingness assumptions follows the
   [National Research Council's methodological guidance](https://www.nationalacademies.org/read/12955/chapter/6);
   its application to these bout outcomes is this review's inference.

4. **P2 — Robustness checks are incomplete, although failures are saved.**
   The difference target has two failed leave-one-fish-out fits, for Delay fish
   `20221116_12` and `20221124_07`. Its US-overlap exclusion fit failed to
   converge. Both random-intercept sensitivities were rejected as singular.
   The successful production-bootstrap optimizer retry does not retry these
   checks (`scripts/review_figure2_g_independent.py:261–295`). The HTML does not
   summarize their failure counts. Retry numerically with the same structure,
   retain each attempt and show failures explicitly. A boundary variance needs
   assessment; it is not evidence that a comparator passed. Do not claim
   robustness to a sensitivity that produced no accepted fit.

5. **P2 — Resume/publication evidence is not yet coherent.**
   The artifact manifest contains a stale hash for `report-complete.json`:
   the manifest is generated at `panel_g_review_extensions.py:455–460`, then
   the completion file is replaced at
   `scripts/review_figure2_g_independent.py:422`. Completed stages are skipped
   without checking their result/input hashes (`:375–380`). There is no run
   lock or atomic publication transaction; several report artifacts are
   overwritten before the final source checks. This run also lacks source
   records for prepare, sensitivities and timing review; prepare has only an
   earlier runner snapshot, and the latter stages were invoked outside the
   guarded CLI. Bind stage dependencies and outputs, verify them before reuse,
   capture complete source dependencies, serialize writes and publish from a
   staged directory. Include completion metadata in the final manifest.
   These issues concern the independent run; the protected selected G hashes
   passed this review.

6. **P2 — A failed full model crashes the subsequent stabilization stage.**
   Population fitting writes only `result.json` when a target fails
   (`scripts/review_figure2_g_independent.py:224–225`). Stabilization then
   unconditionally reads `bootstrap-failures.json`
   (`panel_g_review_extensions.py:243–244`). A temporary-directory reproduction
   produced `FileNotFoundError`. Preserve and propagate the failed-target
   status, suppress its inference and allow the other target/report to finish.
   Add an end-to-end failure-path test.

7. **P2 — The simulation report hardcodes its default settings.**
   `panel_g_review_extensions.py:422–423` describes two repetitions and 39
   refits even when the CLI uses other values. This happens to match the
   inspected run. Build this description from `calibration-status.json`,
   including incomplete or failed simulation counts.
