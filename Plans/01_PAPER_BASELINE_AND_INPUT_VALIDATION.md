# Paper baseline and input validation

## Goal

Establish authenticated, reproducible inputs for the first release of Figures 1–4. This plan owns outstanding baseline work; enduring rules live in [analysis governance](../docs/maintenance/ANALYSIS_GOVERNANCE.md).

## Work

- Identify paper experiments, claims, expected recording inventory and reproducible reference runs; distinguish fixtures from paper data.
- Pin the environment and resolved configuration; record source, code, configuration and baseline-output fingerprints.
- Complete corrected preprocessing and shared detector validation without reopening the author-selected tail bend angular speed metric. Apply the approved bout-only sampling policy.
- Reconcile missing input triplets and timing evidence, including 3sTrace expected-US events. Record missing external inputs explicitly.
- Supply authenticated stage identities to cohort construction and outcome/inference plans; leave primary inclusion and inferential decisions to their owners.

## Acceptance

The paper inventory, reference configuration/environment, preprocessing/detector validation and input hashes are reviewable and mutually traceable. Fixture results do not count as paper-scale validation. Track progress only in the implementation index.
