# Paper figures

Apply [AGENTS.md](../../../AGENTS.md). Use the
[single figure guide](../../../docs/paper/figures/shared/iteration-workflow.md#task-routes)
for the actual request; read only relevant sections and consumed evidence.

1. Classify display, comparison, saved-input preview, legend/presentation edit,
   consistency/layout, scientific work or explicit freeze. Changes to data, masks,
   timing, aggregation, normalization or learner definitions are scientific work.
2. For selected artwork, resolve [Current figures](../../../docs/paper/figures/README.md),
   scoped state, scientific selections, matching legend and source hashes. Check
   real external storage; filenames, caches and open tabs do not select work.
   Disposable saved-input previews need no paper-state bootstrap.
3. Follow the guide's route and use supported tools from the repository root with
   `.venv/bin/python`. Query `nature-main` roles from the unified contract for new
   styling; use the scoped mapping-aware tools for data-bearing coordinate edits.
4. Preserve manual work and complete SVG/resource bundles. Inspect the exact saved
   view before claiming an open. For publication capture starting hashes and use
   locks, fresh relevant evidence and state-last commit. Report incomplete coverage.

Display does not restyle, retention/export does not freeze, and a freeze request
is not permission for unrelated cleanup. Full freeze readiness, mappings, reviews
and panel/assembly/letter requirements are in the guide's explicit-freeze section.
