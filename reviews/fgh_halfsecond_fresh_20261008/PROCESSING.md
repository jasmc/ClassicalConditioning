## Exact operations in this build

1. Select F Delay 20221115_07, G 3 s Trace 20230307_12, H Control 20221115_09; measured Cycle events define CS onsets. Use trials 5-94: Pre-Train 5-14, Train 15-64, Test 65-94. Read the existing corrected-frame angle artifacts and the candidate metric's angular-coverage column. Do not rerun or change shared preprocessing. Hash camera, protocol, angle and coverage files against their manifests/completion markers, and record metadata/code hashes.
2. Estimate cadence from the camera table using the existing stable-reference estimator. Set inferred acquisition time in milliseconds to `anchor + (FrameID - reference_FrameID) * interval_ms`. The anchor is the camera arrival time at the reference row. This is an inferred acquisition clock, not a recorded exposure clock. Read each displayed 40 s window with 2 s context on each side for the detector. Keep recorded arrival time separate from the reconstructed clock.
3. Sum the 16 stored local angles in radians to obtain distal bend `B_i`. Compute raw angular speed `v_i = abs(atan2(sin(B_i-B_(i-1)), cos(B_i-B_(i-1)))) / dt_i`, in rad/ms. Here `dt_i = FrameID_step * interval_ms`. Require valid current and previous corrected frames, consecutive FrameIDs, positive `dt_i <= 10 ms`, and finite raw vigor. Unsupported derivatives are NaN. No new interpolation, temporal angle mean or spatial angle filter is introduced in this review.
4. Detect bouts from raw vigor: centred 7-sample median; centred 21-sample maximum minus centred 401-sample minimum of that smoothed signal. Each rolling operation requires full finite support and never spans a FrameID discontinuity. Detector-valid additionally requires a valid derivative and angular valid-tail fraction >= 0.8. Threshold the envelope at 4 deg/ms (0.06981317008 rad/ms), merge gaps up to the existing 14.285714 ms parameter without crossing invalid support, remove bouts below 57.142857 ms duration, then remove bouts whose raw peak is below 1 deg/ms (0.01745329252 rad/ms). These are the existing detector's rules, not new thresholds chosen for appearance. Exact parameter values and resolved sample windows are in the manifest.
5. In each trial's half-open display window `[-20,20)`, eligible means detector-valid AND moving AND positive bout ID AND finite positive raw vigor. Compute `l_i = ln(v_i)` only for eligible samples. All other samples stay NaN. There is no resting-frame zero fill.
6. For each detected bout represented inside this trial's visible window, compute `q_j = median(l_i)` over its eligible samples in that window. Repeat `q_j` only at that bout's eligible observations. A bout crossing a display boundary is summarized from the visible eligible portion. Detector context is not added to this median. No baseline subtraction occurs at the frame or bout stage.
7. Assign each observation to `[e_k,e_(k+1))`, with `e_k = -20 + 0.5*k`, `k=0,...,79`. Each bin scalar is `b_k = sum(n_jk*q_j) / sum(n_jk)`, where `n_jk` counts eligible samples from bout j in bin k. Empty bins are NaN. This equals the finite-sample mean of the repeated bout values. A longer contribution has more weight; the denominator excludes resting/invalid observations. It measures typical eligible bout intensity on a log scale, not total movement over all frames and not activity occupancy. Save eligible and total frame counts separately. A single eligible contribution is sufficient; no occupancy cutoff is added.
8. Take the finite `b_k` in baseline indices 10-39, exactly `[-15,0)`: at most 30 scalars. Calculate `m = median(b_baseline)`, with each finite bin contributing once, regardless of its frame count. For an even number, this is the average of the two middle values. Calculate P10/P90 from the same scalars using NumPy's linear quantile method. Save the uncentred scalars and reference statistics.
9. The log reference is `z_k = b_k - m`, retaining natural-log units. Display it at +/-0.25 as a diagnostic reference. C is `clip(z_k / ((P90-P10)/2), -1, 1)`. D is `clip(z_k / max(m-P10, P90-m), -1, 1)`. Save both unclipped and clipped C/D values. Quantile division and clipping act only on bin scalars. If the denominator is not positive, the entire corresponding trial is undefined/NaN; no scale is borrowed. One supported baseline bin can define m but cannot define a quantile range.
10. Render only 90 x 80 matrices. Each phase uses vector `pcolormesh` with explicit half-second time edges and trial edges at half-integers, flat shading, no interpolation or rasterized sample field. Each bin is one rectangle. NaN cells are explicitly black. Use `managua_r` and `CenteredNorm(vcenter=0, symmetric halfrange, clip=True)`: zero is coordinate 0.5, colour #582948 with Matplotlib 3.10.9. C/D use +/-1. Vertical green lines indicate CS onset and end (0 and 10 s); the purple Train line indicates the configured US at 9 s for F and 13 s for G. These lines overlay cells; they do not change values or bin boundaries.
